C.O.D.E.:

Quatro agentes.
Quatro identificações.
Mas apenas os que possuem autorização suficiente podem contribuir para o código do cofre.
O sistema vai verificar cada agente e, quando encontrar alguém que atenda ao critério, vai adicionar sua identificação ao código.

Descubra qual será o código final do cofre.

Dica: não basta descobrir quem foi selecionado. Preste atenção no que o sistema faz com os números.

Você está quase lá.
Ou pelo menos é isso que eu fui programado para dizer.

agentes = {
    "Alice": 7,
    "Bruno": 12,
    "Clara": 5,
    "Daniela": 9
}

codigo = 0

for nome, numero in agentes.items():
    if numero > 8:
        codigo += numero

print(codigo)
