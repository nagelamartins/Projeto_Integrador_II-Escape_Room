Temos uma lista de números.
Alguns são pares.
Alguns são ímpares.
E, aparentemente, alguns deles são importantes.

O sistema possui uma regra para decidir quais números entram no código.

Descubra quais números foram selecionados.

Sim, números podem ser suspeitos. Neste lugar, qualquer coisa pode.

numeros = [3, 8, 11, 4, 15, 6]
codigo = 0

for numero in numeros:
    if numero % 2 == 0:
        codigo += numero

print(codigo)
